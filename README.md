# Novara – Landing Page

A responsive landing page for **Novara**, a fictional creative digital studio, built with plain HTML, CSS, and JavaScript (no frameworks or libraries).

---

## Features

- **Header** with logo and navigation (Home, About, Services, Contact), sticky at the top of the page
- **Mobile hamburger menu** that slides in from the side and closes when a link is clicked
- **Hero section** with a headline, subtext, and a call-to-action button
- **About section** with a short company description and key stats
- **Services section** with 6 service cards
- **Testimonials slider** with 3 testimonials, previous/next buttons, dot indicators, and autoplay (pauses on hover)
- **Footer** with company info, quick links, contact details, and social media links
- **Smooth scrolling** between sections
- **Hover animations and transitions** on buttons, cards, and navigation links
- **Fully responsive** layout for mobile, tablet, and desktop

---

## Technologies Used

- **HTML5** – semantic page structure
- **CSS3** – Flexbox, CSS Grid, gradients, transitions, and media queries
- **JavaScript (ES6)** – hamburger menu and testimonials slider

## Responsive Design

| Device  | Screen width    | Behavior                                              |
| ------- | --------------- | ----------------------------------------------------- |
| Desktop | Above 768px     | Full horizontal navigation, multi-column grids        |
| Tablet  | 768px and below | Hamburger menu, slider spacing adjusted               |
| Mobile  | 480px and below | Compact spacing, smaller text, slider arrows hidden   |
